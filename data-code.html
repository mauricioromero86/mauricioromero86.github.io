Medical-provider directory (IPS / REPS)

Colombia’s registry of health-service providers and their branches (from the public REPS registry, prestadores.minsalud.gov.co):

  • Providers (Prestadores) — basic information for each provider
  • Branches (Sedes) — every branch of every provider
  • Services (Servicios) — services provided at each branch
  • Installed capacity (Capacidad Instalada)
  • Branch locations (shapefile)

Source government portals: SISPRO, INVIMA registry, REPS provider registry.
